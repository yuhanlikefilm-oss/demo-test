# Husky Desktop Pet (Electron + Sprite Sheet)

已支持自动识别以下任一位置的素材：
- `asset/husky-sheet.png`
- `assets/husky-sheet.png`

## 运行

```bash
npm install
npm start
```

## 导入方式
1. 你可以手动把文件放进 `asset/` 或 `assets/`。
2. 或在程序里点击右上角 **选择精灵图** 自动导入。

## 当前切图配置
- 每帧: `288 x 220`
- 行顺序: idle / walk / sleep / eat / click
- 帧数: 6 / 4 / 4 / 4 / 5
