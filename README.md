# Husky Desktop Pet (Electron)

已加入**固定可见调试面板**（窗口底部白框），用于显示扫描结果。

## 你当前路径
你的本机路径应是：`D:\GitHub\demo-test\asset`

## 识别规则
- 从项目根目录递归扫描 PNG（最多 4 层）
- 前缀识别：`idle` / `walk` / `sleep` / `eat` / `click-reaction` / `click`

## 启动
```bash
npm start
```

## 若仍不显示
直接把调试面板这两行发我：
- `scanned png: ?`
- `idle:? walk:? sleep:? eat:? click:?`
